# Ресторан «Ташкент» — Восточная кухня & Лаундж

Современный и атмосферный промо-сайт ресторана восточной кухни «Ташкент». Проект демонстрирует богатое кулинарное наследие, авторскую подачу плова, блюда на углях и уютную лаундж-атмосферу.

---

## 🌟 Основные возможности

- **Полноэкранный Hero-слайдер** — приветственная секция с плавной анимацией и слайдами интерьера.
- **Интерактивное меню кухни** — карточки фирменных блюд (Ташкентский плов, Чайханский плов, самса из тандыра, шашлыки, салаты и восточные напитки).
- **Слайдеры атмосферы и интерьера** — демонстрация уюта зала, топчанов, работы мастеров и традиционной керамики.
- **Онлайн-бронирование столиков** — удобное модальное окно с выбором даты, времени, количества гостей и зала.
- **Отзывы гостей** — карусель с впечатлениями посетителей.
- **Контакты и информация** — адрес, часы работы, контактные телефоны и форма связи.
- **100% Адаптивный дизайн** — оптимизирован для смартфонов, планшетов и широкоформатных экранов.
- **Высокая производительность** — использование современных форматов графики (WebP, SVG) и lazy-loading.

---

## 🛠 Стек технологий

- **HTML5** — семантическая и доступная разметка.
- **CSS3** — кастомные свойства (CSS Variables), Flexbox, CSS Grid, анимации и медиа-запросы.
- **Vanilla JavaScript** — без сторонних библиотек и тяжелых зависимостей (слайдеры, навигация, модальные окна).
- **Google Fonts** — типографика *Playfair Display* & *Montserrat*.

## 🚀 Быстрый запуск

Для просмотра проекта достаточно открыть файл `index.html` в любом современном браузере.

Либо запустить локальный сервер:

### С помощью расширения VS Code:
- Установите расширение **Live Server** и нажмите кнопку **«Go Live»** в нижней панели.

### С помощью Python:
```bash
python -m http.server 3000
```
После этого откройте в браузере: `http://localhost:3000`

### С помощью Node.js:
```bash
npx serve .
```

## 🌐 Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub.
2. Перейдите в настройки репозитория: **Settings** → **Pages**.
3. В секции **Branch** выберите ветку `main` и папку `/ (root)`.
4. Нажмите **Save**. Сайт будет доступен по адресу:  
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
